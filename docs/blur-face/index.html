얼굴 모자이크

AI가 얼굴을 찾아서 자동으로 가려줘요. 번호판·이름표도 직접 추가 가능.

🔒 파일은 서버로 전송되지 않아요

사용 방법

  1. 사진을 올리면 AI가 얼굴을 찾아 자동으로 모자이크해요.
  2. 빠진 곳은 사진 위를 끌어서 네모를 추가하고, 필요 없는 네모는 ✕로 빼세요.
  3. 모자이크·흐림 방식과 강도를 고른 뒤 저장하세요.

자주 묻는 질문

얼굴을 못 찾으면 어떻게 하나요?

사진 위를 마우스로 끌어서 가릴 곳을 직접 네모로 그리면 돼요. 번호판, 이름표, 주소도 같은 방법으로 가릴 수 있어요.

사진이 서버로 가나요?

아니요. 얼굴 인식도 내 브라우저 안에서 이뤄져서, 민감한 사진도 안심하고 쓸 수 있어요.

저장한 사진에서 모자이크를 되돌릴 수 있나요?

아니요. 저장된 사진은 원래 모습으로 되돌릴 수 없게 픽셀이 바뀌어요.
