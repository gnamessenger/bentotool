워터마크 넣기

사진·PDF에 글자나 로고를. 여러 장도 한 번에.

🔒 파일은 서버로 전송되지 않아요

이 도구로 할 수 있는 일

사진과 PDF에 글자나 로고 워터마크를 넣는 도구예요. 상품 사진에 브랜드 이름을 넣거나, 신분증·통장 사본에 '○○ 제출용'을 표시하거나, 강의 자료 PDF에 로고를 찍을 때 쓰면 좋아요. 크기·색·투명도·각도를 조절하고 9곳 중 원하는 위치에 두거나 바둑판처럼 반복해서 채울 수 있어요. 여러 파일에 같은 설정을 한 번에 적용하고, 파일은 업로드되지 않아요.

사용 방법

  1. 워터마크를 넣을 사진이나 PDF를 올리세요. 여러 개를 한 번에 올려도 돼요.
  2. 글자 또는 로고를 고르고 크기·색·투명도·각도·위치를 맞추세요. 미리보기가 바로 바뀌어요.
  3. '워터마크 넣고 받기'를 누르면 저장돼요. 여러 개면 ZIP 하나로 받아요.

자주 묻는 질문

신분증 사본에 '제출용' 표시를 하고 싶어요.

글자에 '○○ 제출용'처럼 적고 위치에서 '바둑판 반복'을 고르면 사진 전체에 촘촘히 들어가요. 다른 곳에 함부로 쓰이는 걸 막는 데 도움이 돼요.

PDF도 되나요?

네. PDF의 모든 쪽에 같은 워터마크가 들어가요. 원래 글자는 그대로 남아서 선택·검색도 돼요.

파일이 업로드되나요?

아니요. 내 브라우저 안에서만 처리돼서 민감한 서류도 안심하고 쓸 수 있어요.

사진마다 크기가 다른데 워터마크 크기는 어떻게 되나요?

워터마크 크기는 각 사진의 짧은 변을 기준으로 정해져서, 큰 사진이든 작은 사진이든 비슷한 비율로 들어가요.

알아두면 좋은 팁

  • 사본 악용을 막으려면 '바둑판 반복'에 투명도 30~50% 정도가 좋아요. 내용은 읽히면서 잘라 내기는 어려워요.
  • 로고는 배경이 투명한 PNG로 고르세요. 흰 배경 로고는 네모난 흰 상자가 같이 찍혀요.
  • JPG 사진은 품질 92%의 JPG로, PNG·WEBP는 같은 형식으로 저장돼요. PDF는 모든 쪽에 워터마크 그림이 얹히고 원래 글자는 그대로 남아요.
