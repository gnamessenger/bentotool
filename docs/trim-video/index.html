동영상 자르기

필요한 구간만 쏙. 업로드 없이 내 컴퓨터에서.

🔒 파일은 서버로 전송되지 않아요

이 도구로 할 수 있는 일

동영상에서 필요한 구간만 잘라 MP4로 저장하는 도구예요. 강의·회의 녹화에서 필요한 부분만 남기거나, 긴 영상을 SNS용으로 짧게 자를 때 쓰면 좋아요. 영상 편집 프로그램 ffmpeg를 브라우저용(ffmpeg.wasm)으로 만든 엔진을 써서, 설치 없이 내 컴퓨터 안에서 처리돼요. '빠르게'는 화질 그대로 몇 초 만에, '정확하게'는 원하는 시점에 딱 맞게 잘라요.

사용 방법

  1. 자를 동영상을 올리세요.
  2. 영상을 재생하다가 '지금 위치를 시작으로', '지금 위치를 끝으로'를 누르세요. 숫자(초)로 적어도 돼요.
  3. 빠르게/정확하게 중 고르고 '자르기'를 누르면 MP4가 만들어져요.

자주 묻는 질문

'빠르게'와 '정확하게'는 뭐가 달라요?

'빠르게'는 영상을 다시 만들지 않고 그대로 잘라서 몇 초 만에 끝나고 화질도 그대로예요. 대신 영상이 끊어질 수 있는 지점(키프레임)에서만 자를 수 있어서 시작이 조금(보통 몇 초 이내) 앞당겨질 수 있어요. '정확하게'는 영상을 새로 만들어서 원하는 시점에 딱 맞지만 오래 걸려요.

워터마크가 있나요?

없어요.

영상이 업로드되나요?

아니요. 내 브라우저 안에서만 잘라요.

처음에 시간이 걸리는 이유는요?

처음 한 번은 변환 엔진(약 9MB 다운로드, 압축을 풀면 약 32MB)을 받아야 해요. 그다음부터는 브라우저에 저장돼서 바로 시작돼요.

큰 영상도 자를 수 있나요?

원본은 통째로 메모리에 올리지 않아서 테스트에서 2GB 영상의 10초 구간도 몇 초 만에 잘렸어요. 다만 잘라낸 결과가 1GB를 넘을 만큼 길면 메모리 부족으로 실패할 수 있어요.

알아두면 좋은 팁

  • 영상을 재생하다 원하는 장면에서 멈추고 '지금 위치를 시작으로'를 누르면 편해요. '구간 미리보기'로 확인한 뒤 자르세요.
  • '빠르게'로 잘랐는데 앞부분이 조금 더 들어갔다면 '정확하게'로 다시 잘라 보세요.
  • AVI처럼 브라우저가 미리보기를 못 하는 형식도 시작·끝을 숫자(초)로 적으면 자를 수 있어요.

함께 읽으면 좋은 글

앱 설치 없이 동영상 앞뒤만 자르려면 어떻게 할까요? 앱 설치 없이 브라우저에서 동영상 앞뒤를 자르는 법. '빠르게'와 '정확하게'의 차이를 실측(2초 vs 1분 20초)으로 비교하고, 언제 뭘 고를지와 큰 파일 한계, 휴대폰 기본 기능까지 정리했어요.
