PDF를 JPG로

PDF 페이지를 고화질 이미지로. 한 번에 모두 받기.

🔒 파일은 서버로 전송되지 않아요

사용 방법

  1. 변환할 PDF를 올리세요.
  2. 화질과 형식(JPG·PNG)을 고르세요.
  3. 페이지별로 받거나 '모두 다운로드'로 한 번에 받으세요.

자주 묻는 질문

인스타·블로그에 올리기 좋은 화질은?

'보통'이면 충분해요. 인쇄하거나 글씨를 크게 확대해야 하면 '고화질'을 고르세요.

JPG와 PNG 중 뭘 골라야 하나요?

사진이 많으면 JPG, 글자·도표 위주면 PNG가 더 선명해요.

파일이 업로드되나요?

아니요. 내 브라우저에서만 변환돼요.
