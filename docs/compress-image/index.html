이미지 용량 줄이기

화질은 그대로, 용량은 가볍게. 여러 장도 한 번에.

🔒 파일은 서버로 전송되지 않아요

이 도구로 할 수 있는 일

사진의 가로세로 크기는 그대로 두고(원하면 줄이고) 저장 품질을 조절해 파일 용량을 줄이는 도구예요. 블로그·쇼핑몰 업로드 용량 제한, 메일 첨부, 홈페이지 속도 개선에 쓰면 좋아요. 여러 장을 한꺼번에 올리면 한 장씩 차례로 압축되고, 결과는 JPG 또는 WEBP로 저장돼요.

사용 방법

  1. 품질과 저장 형식을 고르세요. (기본값으로도 충분해요)
  2. 사진을 올리면 바로 압축돼요. 여러 장도 한 번에 돼요.
  3. 한 장씩 받거나 '모두 다운로드'로 한 번에 받으세요.

자주 묻는 질문

얼마나 줄어드나요?

사진에 따라 다르지만 보통 50~80% 줄어요. 품질 값을 낮출수록 더 작아져요.

PNG도 되나요?

네. PNG를 WEBP나 JPG로 저장하면 용량이 크게 줄어요. 투명 배경을 지키려면 WEBP를 고르세요.

사진이 업로드되나요?

아니요. 압축은 내 브라우저 안에서 이뤄지고 사진은 어디로도 전송되지 않아요.

압축했는데 오히려 커지면요?

원본과 같은 형식·같은 크기인데 결과가 더 크면, 자동으로 원본을 그대로 돌려줘요. 품질 값을 낮추거나 '최대 가로 크기'를 줄여 보세요.

알아두면 좋은 팁

  • 품질 60~80 정도면 대부분 눈으로 차이를 느끼기 어려워요. (기본값 70)
  • 휴대폰 사진은 '최대 가로 크기'를 1920px나 1280px로 줄이면 용량이 훨씬 많이 줄어요.
  • JPG로 저장하면 투명한 부분은 흰색이 돼요. 투명 배경을 지키려면 WEBP를 고르세요.
