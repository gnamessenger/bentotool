PDF 페이지 편집

페이지를 보면서 돌리고, 빼고, 순서를 바꿔요.

🔒 파일은 서버로 전송되지 않아요

이 도구로 할 수 있는 일

PDF의 모든 페이지를 작은 그림으로 펼쳐 놓고, 눈으로 보면서 페이지를 돌리고·빼고·순서를 바꾸는 도구예요. 옆으로 누운 스캔 페이지 바로잡기, 빈 페이지나 필요 없는 페이지 빼기, 순서가 뒤섞인 서류 정리에 쓰면 돼요. 페이지를 그림으로 바꾸지 않고 그대로 옮겨 담기 때문에 글자 선택과 화질은 원본과 같아요. 파일은 내 브라우저 안에서만 처리돼요.

사용 방법

  1. 편집할 PDF를 올리면 페이지가 작은 그림으로 쭉 나와요.
  2. ↻로 돌리고 ✕로 빼고, 카드를 끌어서(휴대폰은 ◀ ▶ 버튼) 순서를 바꾸세요.
  3. 'PDF 저장'을 누르면 바뀐 PDF가 저장돼요.

자주 묻는 질문

옆으로 누운 스캔 페이지도 바로잡을 수 있나요?

네. 그 페이지의 ↻ 버튼을 눌러 똑바로 될 때까지 돌리면 돼요. 전체를 한 번에 돌리는 버튼도 있어요.

저장하면 글자나 화질이 바뀌나요?

아니요. 페이지를 그림으로 바꾸지 않고 그대로 옮겨 담기 때문에 글자 선택·화질은 원본과 같아요.

중요한 서류도 괜찮나요?

네. 파일이 서버로 전송되지 않고 내 브라우저에서만 처리돼요.

페이지가 아주 많은 PDF도 되나요?

네. 썸네일은 화면에 보이는 페이지부터 작게 한 장씩 그려서 무겁지 않게 했어요. 다만 아주 큰 파일은 컴퓨터·휴대폰 메모리에 따라 열고 저장하는 데 시간이 걸릴 수 있어요.

알아두면 좋은 팁

  • 실수로 뺀 페이지는 '처음 상태로'를 누르면 모두 돌아와요. (회전·순서도 처음으로 돌아가요)
  • 카드 아래 '원래 n쪽' 표시로 원본에서 몇 쪽이었는지 확인할 수 있어요.
  • 필요한 페이지만 따로 뽑고 싶다면 'PDF 나누기'가, 여러 PDF를 하나로 묶으려면 'PDF 합치기'가 더 빨라요.
