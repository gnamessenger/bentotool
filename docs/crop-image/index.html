이미지 자르기

인스타·유튜브 비율로 딱 맞게. 회전·뒤집기도 돼요.

🔒 파일은 서버로 전송되지 않아요

사용 방법

  1. 자를 사진을 올리세요.
  2. 비율 버튼을 고르고 네모 틀을 끌어서 원하는 부분에 맞추세요.
  3. '자르고 저장'을 누르면 바로 저장돼요.

자주 묻는 질문

인스타그램에 맞는 비율은 뭔가요?

피드는 1:1(정사각형)이나 4:5(세로), 릴스·스토리는 9:16이에요.

화질이 떨어지나요?

자른 부분은 원본 화질 그대로 저장돼요.

사진이 업로드되나요?

아니요. 내 브라우저 안에서만 처리돼요.
