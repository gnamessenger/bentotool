이미지 크기 조절

비율이나 픽셀로 간단하게. 여러 장도 한 번에.

🔒 파일은 서버로 전송되지 않아요

사용 방법

  1. 비율(%)로 줄일지, 가로 크기(px)를 정할지 고르세요.
  2. 사진을 올리면 바로 크기가 바뀌어요. 세로는 비율에 맞춰 자동으로 정해져요.
  3. 한 장씩 받거나 '모두 다운로드'로 한 번에 받으세요.

자주 묻는 질문

사진이 찌그러지지 않나요?

가로세로 비율을 그대로 지켜서 찌그러지지 않아요.

여러 장을 같은 크기로 맞출 수 있나요?

네. '가로 크기(px)'를 고르면 모든 사진의 가로 폭이 같아져요.

사진이 업로드되나요?

아니요. 내 브라우저 안에서만 처리돼요.
