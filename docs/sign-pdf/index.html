PDF 서명 넣기

출력하고 스캔할 필요 없이, 서명·도장을 바로 넣어요.

🔒 파일은 서버로 전송되지 않아요

이 도구로 할 수 있는 일

계약서·신청서·동의서 같은 PDF에 서명이나 도장을 넣는 도구예요. 마우스나 손가락으로 직접 서명을 그리거나, 서명·도장 이미지를 올리거나, 이름·날짜를 글자로 적어서 원하는 페이지의 원하는 자리에 놓으면 돼요. 여러 개를 넣을 수 있고, 같은 서명을 모든 쪽 같은 자리에 한 번에 넣을 수도 있어요. 파일은 내 브라우저 안에서만 처리돼요.

사용 방법

  1. 서명할 PDF를 올리세요.
  2. 서명을 직접 그리거나, 도장·서명 이미지를 올리거나, 이름·날짜를 적어 '넣기'를 누르세요.
  3. 페이지 위에서 끌어서 자리를 옮기고, 모서리 동그라미로 크기를 맞춘 뒤 저장하세요.

자주 묻는 질문

휴대폰에서도 서명할 수 있나요?

네. 서명 칸에 손가락으로 그리면 돼요. 페이지 위의 서명도 손가락으로 끌어서 옮길 수 있어요.

도장 사진 뒤의 흰 배경은요?

'흰 배경 투명하게'를 켜 두면 흰색에 가까운 부분이 투명해져서 도장만 찍힌 것처럼 보여요. 배경이 이미 투명한 PNG는 그대로 써요.

이걸로 넣은 서명은 법적으로 인정되나요?

이 도구는 PDF 위에 서명 그림을 얹어 주는 기능만 해요. 공동인증서 같은 전자서명 인증 정보는 들어가지 않아요. 효력이 중요한 문서라면 받는 곳에 이 방식이 괜찮은지 먼저 확인하세요.

넣은 글자도 PDF에서 검색되나요?

아니요. 한글 글꼴을 PDF에 넣지 않고 글자를 그림으로 바꿔서 넣기 때문에, 넣은 이름·날짜는 선택하거나 검색할 수 없어요. 원래 PDF에 있던 글자는 그대로예요.

알아두면 좋은 팁

  • 도장은 흰 종이에 찍어 밝은 곳에서 위에서 똑바로 찍은 사진이 가장 깔끔하게 투명해져요.
  • 직접 그릴 때는 서명 칸을 넉넉히 쓰고 크게 그린 뒤, 페이지에서 크기를 줄이면 더 매끈해 보여요.
  • 한 번 만든 서명은 '만든 서명'에 남아 있어서, 다른 페이지로 넘어가 눌러 주면 또 넣을 수 있어요. (새로고침하면 사라져요)
