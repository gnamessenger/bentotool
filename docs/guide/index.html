사용법·꿀팁

일하다 자주 막히는 파일 문제를 직접 해 보면서 정리했어요. 글마다 바로 쓸 수 있는 무료 도구를 연결해 두었어요.

아이폰 사진(HEIC)이 PC에서 안 열릴 때, 어떻게 해야 할까요? 아이폰 사진(HEIC)이 윈도우 PC나 업로드 사이트에서 안 열릴 때, 이미 찍은 사진을 JPG로 바꾸는 법과 앞으로 JPG로 찍는 설정, 옮길 때 자동 변환까지 상황별로 정리했어요. '사진은 ○○KB 이하만 올릴 수 있어요' 오류, 어떻게 해결할까요? 원서·민원·지원서 사이트에서 '사진은 200KB 이하' 같은 오류가 날 때, KB 계산법(1000과 1024 차이)부터 화질을 지키며 용량을 맞추는 순서까지 직접 해 본 숫자로 설명해요. 이력서 증명사진, 규격은 뭘로 하고 집에서는 어떻게 만들까요? 이력서·입사지원용 반명함(3×4cm) 등 흔한 증명사진 규격, 여권사진을 집에서 만들 때 주의할 점, 집에서 잘 찍는 요령과 4×6 인화·온라인 접수용 파일 만드는 법까지 정리했어요. PDF 계약서에 프린트 없이 서명·도장 넣는 법 PDF로 받은 계약서·동의서에 출력·스캔 없이 서명을 그려 넣고, 도장 사진을 투명하게 얹고, 이름·날짜까지 넣는 방법. 서명 그림과 전자계약 서비스의 차이도 정리했어요. PDF 페이지 순서 바꾸기, 빼기, 돌리기 한 번에 하는 법 스캔하다 거꾸로 들어간 쪽, 옆으로 누운 쪽, 빈 쪽이 섞인 PDF를 미리보기로 보면서 돌리고 빼고 순서를 맞추는 법. 글자·화질이 그대로인 이유까지 직접 확인했어요. 제출 서류 여러 개(PDF+사진)를 PDF 하나로 합치는 순서 지원서 PDF와 자격증 사진처럼 섞여 있는 제출 서류를 PDF 하나로 합치는 순서. 사진을 PDF로 바꾸기, 순서 정하기, 파일 이름, 용량 줄이기까지 직접 해 본 숫자로 정리했어요. 휴대폰으로 찍은 서류 사진, 어떻게 PDF로 만들까요? 휴대폰으로 찍은 서류 사진을 깔끔한 PDF로 만드는 법. 그림자·기울기 없이 찍는 요령, 필요한 부분만 자르기, A4로 묶기, 용량 줄이기, 아이폰·구글 드라이브 스캔 기능까지 정리했어요. PDF 용량이 커서 메일이 안 보내질 때, 어떻게 할까요? PDF가 커서 메일 첨부나 업로드가 안 될 때, 왜 큰지 확인하는 법부터 압축 강도 고르기, 그래도 크면 나눠 보내기까지. Gmail·Outlook·다음 메일 첨부 한도도 공식 안내로 정리했어요. 사진이나 캡처 속 글자, 다시 치지 않고 복사하는 법 사진·캡처 속 글자를 복사하는 OCR, 직접 만든 샘플로 정확도를 재 봤어요. 잘 읽히는 사진 조건, '사진 보정' 켜는 때, 한글·영문 섞인 글에서 자주 틀리는 것, 휴대폰 기능과 비교까지. 상품 사진, 집에서 흰 배경으로 깔끔하게 만들려면? 스마트스토어·오픈마켓에 올릴 상품 사진을 집에서 흰 배경으로 만드는 법. 촬영 요령, AI 배경 제거 후 흰색 JPG 저장, 정사각형 자르기, 네이버 공식 권장 규격까지 정리했어요. 사진 올리기 전에 얼굴과 개인정보, 어떻게 가릴까요? 단체사진·아이 사진·행사 사진을 올리기 전에 다른 사람 얼굴과 차량번호·주소·택배 송장을 가리는 법. 자동 얼굴 찾기가 놓치는 경우와 모자이크·흐림 차이를 직접 해 본 결과로 정리했어요. 내 사진과 상세페이지, 워터마크로 도용을 줄이려면? 내 사진과 상세페이지 이미지 도용이 걱정될 때 글자·로고 워터마크 넣는 법. 투명도·위치·바둑판 반복 고르는 기준, 여러 장과 PDF 한 번에 처리, 워터마크의 한계까지 정리했어요. 여행 사진 속 지나가는 사람·전깃줄, 어떻게 지울까요? 여행 사진에 끼어든 행인, 하늘을 가로지르는 전깃줄, 바닥의 잡동사니를 AI로 지우는 법. 붓 크기 고르기, 나눠서 지우기, 잘 되는 경우와 안 되는 경우를 직접 해 본 결과로 정리했어요. 작은 사진·옛날 사진, 화질을 키울 수 있을까요? 작거나 오래된 사진을 AI로 2배·4배 키우는 법. 그냥 늘리기와 무엇이 다른지, 효과가 큰 사진과 작은 사진, 크기 제한, 인화·상세페이지에 쓸 때 주의점을 실제로 잰 처리 시간과 함께 정리했어요. 가게·명함용 QR코드, 무료로 만들어도 괜찮을까요? 가게·명함·전단지에 넣을 QR코드를 무료로 만드는 법. 기한 없는 정적 QR과 유료 동적 QR의 차이, 와이파이 QR, 인쇄 크기·여백·색 대비, 인쇄 전 휴대폰 확인까지 정리했어요. 자기소개서 글자 수, 공백 포함일까 제외일까? 자소서 글자 수 제한, 공백 포함인지 제외인지, 바이트로 세면 한글이 몇 바이트인지 헷갈릴 때. 세는 기준의 차이와 사이트마다 다른 점, 글자 수를 딱 맞추는 요령을 예시 숫자로 정리했어요. 동영상에서 소리만 MP3로 뽑으려면 어떻게 할까요? 강의·회의 녹화 영상에서 소리만 MP3로 뽑는 법. 96~320kbps 음질별 1분당 용량, 직접 해 본 변환 시간, 결과 확인 요령과 긴 영상을 다룰 때 주의점까지 정리했어요. 영상 자막(SRT), 무료로 자동으로 만들 수 있을까요? AI 받아쓰기로 영상 자막(SRT·VTT)을 무료로 만드는 법. 빠름·정확·가장 정확 모델의 첫 다운로드 크기와 실제 걸린 시간, 한국어 오인식 고치는 요령, 유튜브·프리미어에 넣는 법까지. 앱 설치 없이 동영상 앞뒤만 자르려면 어떻게 할까요? 앱 설치 없이 브라우저에서 동영상 앞뒤를 자르는 법. '빠르게'와 '정확하게'의 차이를 실측(2초 vs 1분 20초)으로 비교하고, 언제 뭘 고를지와 큰 파일 한계, 휴대폰 기본 기능까지 정리했어요. 아이폰 MOV 영상, MP4로 어떻게 바꿀까요? 아이폰 MOV 영상이 PC나 업로드 사이트에서 안 열리는 이유(HEVC 코덱)와 MP4로 바꾸는 법. 몇 초면 끝나는 옮겨 담기와 다시 인코딩 시간, 용량 줄이기, 500MB 경고 이유까지 실측으로 정리했어요.
