How to use

  1. Paste or type your text.
  2. Word, character and sentence counts update as you type.
  3. Set a goal to see how much is left.

FAQ

Does it count spaces?

It shows both: characters with spaces and without spaces.

How is reading time calculated?

Based on an average reading speed of about 200 words per minute.

Is my text saved?

Never on a server. A draft is kept only in your browser so you don't lose it if you close the tab.
