Split PDF

Pull out just the pages you need, or split them all.

🔒 Files never leave your device

How to use

  1. Add the PDF you want to split.
  2. Type pages like 1-3, 5 — or choose 'Split every page'.
  3. Click the button to download.

FAQ

How do I enter pages?

Separate with commas and use hyphens for ranges, e.g. 1-3, 5, 8-10

How do I get split pages?

Each page becomes its own PDF, bundled in one ZIP file.

Is it safe for sensitive documents?

Yes. Files are never sent to a server.
