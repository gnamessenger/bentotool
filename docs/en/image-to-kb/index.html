What this tool does

This tool automatically shrinks photos to a file size you choose — 100KB, 200KB, 1MB or any custom value. Use it whenever a form says 'photo must be under ___KB': government services, job applications, exam registrations. It first lowers the quality step by step and, if that's not enough, reduces the dimensions, keeping the best quality that still fits. Each result is checked and marked if it's under the target, and iPhone HEIC photos are accepted directly.

How to use

  1. Pick a target size (e.g. 100KB, 200KB, 1MB, or enter your own).
  2. Drop your photos — each is shrunk until it fits under the target. Many at once is fine.
  3. Check the 'under target' mark and download one by one or use 'Download all'.

FAQ

When is this useful?

Whenever a site says 'photo must be under ___KB' — government forms, job applications, exam registrations, school submissions.

How does it shrink the file?

It first lowers the JPG quality step by step; if that's not enough, it reduces the width and height gradually. It keeps the best quality that still fits.

Are my photos uploaded?

No. Everything runs in your browser and your photos are never sent anywhere.

The site also requires a specific width in pixels.

First set the width with 'Resize Image', then come back and choose 'Keep dimensions' so only the file size is reduced.

It says it couldn't reach the target.

This happens with very small targets or when 'Keep dimensions' is selected. Try a slightly larger target or switch to 'Auto'. Results that miss the target are clearly marked with ⚠.

Tips

  • 1KB is counted as 1,000 bytes, so results also pass on sites that count 1KB as 1,024 bytes.
  • For ID photos, a very small target makes faces blurry. Choosing the largest allowed size gives the sharpest result.
  • Most application sites only accept JPG. Keep JPG unless WEBP is specifically requested.
